# Sylva

Standalone website project for the Sylva restoration and native-planting site.

## Start locally

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run
`npm run build`; run `npm run preview` to preview that build locally.

The setup script copies the pinned Three.js browser build into Vite's public
assets so the supplied page can use its existing script URL.
